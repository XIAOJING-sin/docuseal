# DocuSeal 使用指南（简体中文）

> 适用对象：日常使用 DocuSeal 进行模板制作、发送签署与管理归档的同事（管理员/编辑/查看者/签署人）。
>
> 本指南默认你已经有一个可登录的账号与工作区（Workspace/Account）。

---

## 1. 快速开始

### 1.1 登录与语言切换
- 打开系统登录页，输入邮箱与密码登录。
- **语言切换**：
  - 登录页通常可通过页面语言选择或 URL 参数 `?lang=zh` 切换为中文。
  - 登录后，语言会跟随你选择的语言/账号语言设置（如管理员设置了默认语言）。

### 1.2 角色与权限（最常见）
不同部署/配置可能略有差异，以下为典型行为：
- **管理员（Admin）**：可查看与管理整个工作区所有模板/提交记录；管理用户、设置、Webhook 等。
- **编辑（Editor）**：可创建模板与发起提交；通常仅能管理自己创建的内容（若开启“私有工作区”）。
- **查看者（Viewer）**：只读查看（通常不能创建/编辑模板）。
- **签署人（Signer/Recipient）**：通过邮件或链接打开签署页面完成签名/填写。

> 如果管理员开启了“私有工作区（Private workspace）”，非管理员一般只能看到自己创建的模板与提交记录。

## 2. 模板（Template）：创建、上传文件、设计字段

### 2.1 创建模板
1. 进入 **Templates（模板）**。
2. 点击 **New template / 新建模板**。
3. 输入模板名称（建议：业务场景 + 版本号，例如：`Offer Letter v1`）。

### 2.2 上传文件（PDF/图片等）
模板编辑器里通常会有以下任一方式：
- **上传 PDF**：点击 **Upload / 上传**，选择本地 PDF 文件。
- **拖拽上传**：将 PDF 文件直接拖到编辑区。

上传成功后，你会在画布上看到 PDF 页面缩略图/预览。

#### 常见问题：上传失败/无权限
如果你是 Editor 且“上传文件”按钮不可用或提示无权限：
- 先确认你打开的是你**有权限编辑**的模板（通常是你创建的模板，或管理员授予你的权限）。
- 如果仍失败：请管理员检查你的角色权限与“私有工作区”配置。

### 2.3 在模板上放置字段（文本/日期/勾选/签名）
1. 在左侧字段面板选择一个字段类型，例如：
   - **Text / 文本**
   - **Date / 日期**
   - **Checkbox / 勾选**
   - **Signature / 签名**
   - **Initials / 首字母**
2. 将字段拖到 PDF 目标位置。
3. 点击字段进行属性设置，常见属性：
   - **Assigned to / 分配给**：指定由哪个签署人填写（例如：候选人、HR）。
   - **Required / 必填**：勾选后签署人必须填写才能提交。
   - **Default value / 默认值**（若支持）：预填内容。

#### 多签署人（多人签署）
当需要多人签署时：
1. 在模板中添加多个签署角色（如：`Signer 1`、`Signer 2` 或按姓名/角色）。
2. 每个字段都要明确“分配给谁”，否则可能导致签署流程不清晰或无法提交。

### 2.4 保存与发布
- 点击 **Save / 保存** 保存模板。
- 若系统有“发布/启用”概念，请确保模板处于可用状态。

## 3. 发送签署（Submission）：发起、跟踪、归档

### 3.1 从模板发起签署
1. 打开一个模板，点击 **Send / 发送** 或 **Create submission / 创建提交**。
2. 填写签署人信息：
   - 邮箱（Email）
   - 姓名（Name，可选但强烈建议填写）
3. 如有抄送/自定义邮件内容/到期时间等选项，可按业务需求配置。
4. 点击 **Send / 发送** 发起签署。

> 如果未配置 SMTP/邮件发送，系统可能会提供“分享链接”方式（见下一节）。

### 3.2 分享链接（无需邮件）
某些场景会使用分享链接（例如：前台自助填写）：
1. 在模板或提交页找到 **Share link / 分享链接**。
2. 复制链接发给签署人。
3. 签署人打开链接即可填写与签署。

---

## 4. 签署端（Signer）：如何上传/设置签名并完成签署

签署人打开签署页面后，通常按页面引导逐项完成字段。

### 4.1 设置签名（Signature）
点击签名字段后，系统一般提供以下方式（视配置而定）：
- **手写绘制**：在画板上用鼠标/触控书写签名。
- **键入签名**：输入姓名，系统生成签名字体。
- **上传图片**：上传签名图片（PNG/JPG），建议透明背景 PNG，清晰度更高。

设置完成后点击 **Apply / 应用**。

### 4.2 设置首字母（Initials）
流程与签名类似：
- 可绘制/键入/上传。
- 适用于每页角落“确认”类字段。

### 4.3 完成与提交
1. 逐项填写所有必填字段（Required）。
2. 点击 **Finish / Submit / 完成提交**。
3. 完成后：
   - 签署人可能会看到下载/预览选项（取决于权限与配置）。
   - 发起人可在提交记录中查看状态更新。

## 5. 管理提交记录：状态、下载、归档、删除

### 5.1 查看提交状态
1. 进入 **Submissions（提交记录）** 列表。
2. 点击任意一条提交记录进入详情页。
3. 常见状态（名称可能略有差异）：
   - **Draft / 草稿**：尚未发送或未完成配置。
   - **Sent / 已发送**：已发给签署人（邮件或链接）。
   - **Viewed / 已查看**：签署人打开过链接。
   - **Completed / 已完成**：所有必填字段已填写，签署完成。
   - **Declined / 已拒绝**：签署人拒绝签署（若启用）。
   - **Expired / 已过期**：超过有效期（若设置了到期时间）。
   - **Archived / 已归档**：从主列表隐藏，但仍可恢复或保留记录（推荐用于“删除”需求）。

### 5.2 下载已签署文件
1. 进入提交详情页。
2. 点击 **Download / 下载**（若有多个文件，可能会分别下载“原始文件/已签署文件/证书”等）。
3. 如果你找不到下载按钮：
   - 先确认该提交已完成（Completed）。
   - 或者你是否只有查看权限（Viewer）且被限制下载（取决于管理员设置）。

### 5.3 归档（推荐的“删除”方式）
归档适用于：不想在列表里继续看到，但希望保留审计记录/可追溯。
1. 在提交详情页或列表操作菜单中选择 **Archive / 归档**。
2. 归档后该记录会从默认列表消失（通常可在“Archived/归档”筛选中找到）。

### 5.4 删除 vs 永久删除（重要）
- **删除（软删除/归档）**：一般指“归档”，可恢复、可追溯，推荐日常使用。
- **永久删除（Permanently delete）**：会不可逆移除相关记录/文件。
  - 通常**仅管理员**允许永久删除。
  - 编辑/查看者一般不允许永久删除（但可以归档自己创建的内容，视权限配置）。

## 6. 模板管理：文件夹、复制、归档

### 6.1 使用文件夹整理模板
1. 在模板列表中创建或选择一个文件夹（Folder）。
2. 将模板移动到文件夹：
   - 打开模板 → **Move / 移动** → 选择目标文件夹 → 保存。

> 如果你在“私有工作区”中看不到别人的模板，文件夹仍可能可见，这是正常的：文件夹用于分类，但模板可见性仍由权限控制。

### 6.2 复制模板（做版本）
建议用复制功能生成新版本：
- 例如从 `Offer Letter v1` 复制为 `Offer Letter v2`，再进行编辑与发布。

### 6.3 归档模板
- 归档不等于永久删除，更适合“下线模板但保留历史”。
- 对于编辑（Editor），通常只允许归档/管理自己创建的模板（取决于管理员是否开启“私有工作区”）。

## 7. 管理员常用设置（Admin）

### 7.1 邀请/创建用户与分配角色
1. 进入 **Settings / 设置** → **Users / 用户**。
2. 添加用户邮箱，分配角色（Admin/Editor/Viewer）。
3. 若未配置 SMTP，建议为新用户设置初始密码或使用管理员手动分发登录信息（具体策略由你们内部决定）。

### 7.2 开启/关闭“私有工作区（Private workspace）”
用途：让非管理员只能看到**自己创建**的模板与提交记录。
1. 进入 **Settings / 设置** → **Account / 账户偏好**。
2. 找到 **Private workspace / 私有工作区** 开关：
   - 开启：Editor/Viewer 默认仅能看自己创建的内容。
   - 关闭：Editor/Viewer 可按更宽松规则查看（视权限配置）。

### 7.3 邮件（SMTP）与通知
如需通过邮件发送签署邀请/提醒：
- 配置 SMTP 后，系统才能自动发邀请邮件。
- 若不配置 SMTP，可使用“分享链接”完成签署流程。

### 7.4 品牌（Logo / Favicon / 支持邮箱）
如果你们需要白标（white-label）体验：
- **左上角 Logo（模板编辑器等）**：替换 `public/logo.svg`。
- **浏览器 Tab 图标（favicon）**：替换 `public/favicon.ico`。
- **支持邮箱**：若你们部署已支持通过环境变量配置，可设置 `SUPPORT_EMAIL` 为你们自己的邮箱或留空隐藏。

> 替换静态资源后，如浏览器仍未更新，请使用强制刷新（Windows：`Ctrl + F5`）。

## 8. 常见问题（FAQ）

### 8.1 我是编辑（Editor），为什么看不到同事的模板/提交？
可能原因：
- 管理员开启了 **私有工作区（Private workspace）**。
- 你没有被授予跨用户访问权限（这通常是预期行为）。

### 8.2 我上传文件失败/按钮灰色
排查思路：
- 你是否有该模板的编辑权限（通常需要对模板有 `update` 权限）？
- 模板是否处于“只读/已归档”状态？
- 文件是否过大或格式不支持（部署可能配置了大小限制）？

### 8.3 签署人不会设置签名怎么办？
建议给签署人一句话指引：
- “点签名框 → 选择手写/键入/上传图片 → 应用 → 最后点完成提交。”

### 8.4 语言切换后又变回英文
一般处理：
- 确认 URL 是否带 `?lang=zh`（尤其是登录页）。
- 登录后在设置里将账号默认语言设为中文（若有该选项）。
- 强制刷新一次，避免缓存。

## 9. 建议的内部使用规范（推荐）
- **模板命名**：业务 + 版本（例如：`NOVA Offer Letter v3`）。
- **字段规范**：所有签名/日期字段设置为必填；字段“分配给谁”必须明确。
- **删除策略**：日常用“归档”替代永久删除；永久删除仅管理员执行并记录原因。
